## 四、假设与决策记录

1. **前端置于仓库根**（`src/`、`package.json` 在根目录），与 `create-tauri-app` 官方模板一致；`src-tauri/frontendDist = "../dist"`。
2. **workspace.dependencies 先声明后启用**：P0 不引入实际依赖编译，缩短骨架构建时间；P1 取消注释即可。
3. **`core_version` 命令**：唯一的跨层冒烟测试通道，验证「前端 → Tauri 命令 → format_core」链路，不含业务逻辑。
4. **Svelte 5 runes 语法**（`$state` / `$effect`）。
5. **identifier** 暂定 `edu.paper-format.auditor`，可在发布前调整。
6. **main.rs 采用 lib+bin 分离结构**（Tauri 2 官方推荐，便于未来支持移动端 `mobile_entry_point`）。

## 五、遗留事项（需在开发机执行）

1. **生成应用图标**：`src-tauri/icons/` 目前为空。在装有 Rust 的开发机上运行：
   ```bash
   pnpm tauri icon /path/to/logo.png
   ```
   （或临时将 `tauri.conf.json` 的 `bundle.active` 设为 `false` 以跳过打包图标校验。）
2. **Linux 系统依赖**（`pnpm tauri dev` 前置条件，Debian/Ubuntu 示例）：
   ```bash
   sudo apt install libwebkit2gtk-4.1-dev build-essential curl wget file \
     libxdo-dev libssl-dev libayatana-appindicator3-dev librsvg2-dev pkg-config
   ```
   Windows/macOS 无需此步骤。
3. 首次 `pnpm tauri dev` 会全量编译 Tauri 依赖树，耗时较长属正常现象。
